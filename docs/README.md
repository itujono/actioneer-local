# Documentation Status

⚠️ **Important Notice**: As of January 2025, Actioneer has transitioned to a pure web OAuth architecture.

## Current Documentation

All documentation in this folder reflects the **legacy Gmail add-on approach** and is now **outdated**.

## Current Architecture (2025)

Actioneer now uses:

- **Pure Web OAuth**: Direct Gmail API access through web authentication
- **No Add-ons**: No Google Workspace Marketplace installations required
- **Simplified Flow**: Visit actioneer.online → OAuth → Automatic processing
